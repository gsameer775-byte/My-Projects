# Hikayat Banaras — Saree Store Management System

## Modules
- Inventory (Saree records, categories, stock)
- Sales / POS (billing, invoices, returns)
- Customers / CRM (loyalty, credit ledger, campaigns, reminders)
- Staff (roles, attendance, salary & commission)
- Vendors (purchase orders, payments)
- Expenses
- Reports (sales, stock, staff performance, profit & loss)
- Settings (users, roles, audit log)

## Setup (localhost)
1. Create a MySQL database named `hikayat_banaras`.
2. Import the schema SQL (to be provided step-by-step).
3. Update `config/db.php` with your local DB credentials.
4. Point your local server (XAMPP/WAMP/Laragon) document root to this folder.
5. Visit `admin/login.php` to begin.
